# Detection example attribution

Two README examples are sourced from Wikimedia Commons. The Visa test-card
screenshot comes from a public GitHub demo, and the Chinese ID specimen was
supplied by the project owner. The downloaded copies were re-encoded as PNG to
remove metadata; the `*-redacted.*` variants were additionally modified by
applying mosaic redaction.

The SMTP and Visa-card examples contain documentation-only test data. The
source demo explicitly describes the card as fake and requires the displayed
number for its test checkout.
